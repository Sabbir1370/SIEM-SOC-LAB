# SIEM/SOC Lab Setup (Wazuh + Ubuntu Server + PuTTY)

## Overview
This project demonstrates the setup of a basic SIEM/SOC lab environment using Wazuh installed on an Ubuntu Server virtual machine. The system is accessed remotely using PuTTY via SSH from a host machine.

The goal is to understand core SIEM deployment, Linux server management, and remote administration concepts used in SOC environments.

---

## Tools Used
- VirtualBox (Virtual Machine)
- Ubuntu Server (LTS)
- PuTTY (SSH Client)
- Wazuh SIEM Platform
- Parrot OS (Host System)

---

## Summary of Work
- Created and configured Ubuntu Server in VirtualBox
- Enabled SSH for remote access
- Connected to VM using PuTTY
- Installed Wazuh SIEM (all-in-one setup)
- Verified running services and system status

---

## Result
The SIEM lab environment was successfully deployed and is operational. The system is capable of remote access and security monitoring using Wazuh.
